## Технологии

- **HTML5** — семантическая разметка, 21 страница
- **CSS3** — CSS-переменные, Grid, Flexbox, медиа-запросы, тёмная/светлая тема
- **Vanilla JavaScript** — без фреймворков и библиотек
- **JSON** — локальная база данных товаров (`data/db.json`, 30 товаров, 10 категорий)
- **localStorage** — корзина, избранное, сравнение, просмотренные, настройки пользователя

## Функциональность

- Адаптивная верстка (1440 / 768 / 320 px)
- Тёмная и светлая темы
- Интернационализация (RU / EN)
- Версия для слабовидящих (5 цветовых схем, 3 размера шрифта, крупный шрифт)
- Корзина, Избранное, Сравнение, Просмотренные товары
- Hero-слайдер с автопрокруткой
- Карусели товаров с пагинацией
- Фильтры каталога (цена, бренд, категория)
- Аккордеон (FAQ, условия)
- Модальные окна (вход, регистрация, корзина, выбор города)
- Форма обратной связи + Яндекс.Карта
- Мобильное бургер-меню с подменю каталога
- Маска ввода телефона (+375)
- Регистрация / авторизация пользователей (база данных `db.json`)
- Корзина с оформлением заказа и автозаполнением данных
- Toast-уведомления
- Прелоадер на каждой странице
- SEO-оптимизация (мета-теги, Open Graph)
